# VISION PRO

Proyecto independiente para Android TV / Android con backend Node.js y PostgreSQL (Neon).

## Estado
- Base de datos Neon production: 11 tablas aplicadas y verificadas.
- API Node.js: base inicial incluida.
- Android: Kotlin + Jetpack Compose + Media3 como punto de partida.
- APK: pendiente de compilación y pruebas en Android Studio.
- Añadir únicamente contenido propio, licenciado, de dominio público o listas que tengas autorización para usar.

## Backend
Configura `DATABASE_URL` y `JWT_SECRET` como variables secretas del servicio. Nunca incluyas credenciales en la APK ni en Git.
